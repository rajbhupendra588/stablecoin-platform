# Stablecoin Platform

Enterprise-grade B2B stablecoin settlement platform for commercial payments, invoice-driven payouts, treasury operations, and ledger reconciliation.

## What is in this repo
- Multi-module Spring Boot backend
- React frontend
- Kafka-based event flow
- PostgreSQL persistence
- Stablecoin settlement adapters
- Audit and reconciliation support
- Infrastructure and CI scaffolding

## Build
This repository is being developed milestone-by-milestone. The target is a production-quality reference implementation with clean module boundaries, tests, and deployable artifacts.
